# Imagens do produto

A landing tem 10 espaços de imagem. Enquanto o arquivo não existe aqui, o
lugar mostra um quadro tracejado dizendo qual nome ele espera. Assim que você
subir a imagem com esse nome exato, ela aparece sozinha — não precisa mexer no
código.

| Arquivo | Onde aparece |
|---|---|
| `capa-principal.png` | Capa do kit, no topo da página |
| `amostra-1.png` | Slider de amostras — folha de cartas impressa |
| `amostra-2.png` | Slider de amostras — cartas recortadas |
| `amostra-3.png` | Slider de amostras — página de regras |
| `amostra-4.png` | Slider de amostras — crianças usando as cartas |
| `atividades-extras.png` | Caça-palavras e jogo da memória |
| `bonus-premium.png` | Os 4 bônus do Kit Premium juntos |
| `material-1.png` | Folha de cartas dentro do PDF |
| `material-2.png` | Página de regras do jogo |
| `dinamicas-biblicas.png` | Materiais bônus impressos |

Use PNG com fundo transparente ou JPG. Largura recomendada: 900 a 1400 px.
